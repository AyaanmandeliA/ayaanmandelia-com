# ayaanmandelia-com

Source for my personal website: https://ayaanmandelia.com

## What it is

A seven-page personal site covering who I am, what I build, short written notes, my Off Script content, a timeline and press.

## How it works

It is a Next.js App Router site. The public pages (home, about, projects, notes, off-script, timeline, press) live under `app/(site)/` and share one layout with the masthead, footer and frame. Page copy, the timeline and the notes are kept in a single content module (`lib/content.ts`) and rendered by the page components, so text changes happen in one place. Shared achievement wording and the canonical site URL are in `lib/achievements.ts` and `lib/site.ts`. Metadata, a sitemap and robots rules are generated by Next.js route files, and a redirect sends the `www` host to the apex domain. Entrance animations use the `motion` library, and there is an optional static-export mode for snapshots.

## Stack

Next.js, React, TypeScript, Tailwind CSS, motion.
